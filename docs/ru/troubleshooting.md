# Если что-то не так

**`Memory access fault by GPU node-N` под нагрузкой, сервер перезапускается.**
На gfx906 падают пути сохранения/восстановления состояния разговора. Держите
`--cache-reuse 0 --cache-ram 0 --ctx-checkpoints 0` (run.sh так и делает). Проверено: 6 из 6 чистых
нагрузочных прогонов по 900 с с ними; без них отказ приходил на 7-м запросе. Цена: кэш промпта
работает только для одного разговора на слот — отсюда `--parallel 1` и один агент на сервер.

**Вся машина зависает / перезагружается во время генерации с `-sm tensor`.**
Взаимная блокировка в all-reduce на ROCm 6.3 и неудачный сброс карты. Используйте этот образ
(ROCm 7.14). Если всё равно случается — откатитесь на `EXTRA="--split-mode layer"` или уберите MTP
(`MTP=0`) и сообщите.

**`-sm tensor` почти не быстрее `layer` (или медленнее).**
Нет P2P между картами. `scripts/check-system.sh` → исправьте размещение MMIO в BIOS
([hardware.md](hardware.md), §2).

**Всё медленно, `mem_info_vis_vram_total` = 268435456.**
Выключен `Above 4G Decoding` (или сбросился из-за севшей батарейки CMOS).

**Модель бесконечно думает или слишком поздно начинает действовать (агенты).**
Стоковый шаблон Qwen превращает `effort: high` от Claude Code в `xhigh`; используйте шаблон по
умолчанию `TEMPLATE=agent`. Размышление ограничено на сервере `REASONING_BUDGET` (8192): Claude Code
не шлёт `MAX_THINKING_TOKENS`. Не ставьте меньше ~768 — оборванная мысль молча даёт недоделанный ответ.

**Ошибка `System message must be at the beginning` с Claude Code.**
То же лечение: `TEMPLATE=agent`.

**K-кванты (`Q4_K_M`, `IQ*`) медленные.** Быстрого кернела под gfx906 для них нет. Берите `Q4_0` (или `Q4_1`).

**`llama-bench` кладёт всё на одну карту и падает по памяти.**
В `llama-bench -ts` пишется косая черта (`1/1`); запятая значит «перебрать варианты».
У `llama-server` — `1,1`.

**Docker не может открыть `/dev/kfd`.** Добавьте пользователя в группы `video` и `render`
(`sudo usermod -aG video,render $USER`, перелогиниться) — run.sh пробрасывает обе группы в контейнер.

**Сборка падает с `anchor ... found 0 times`.** Под заплатой изменился тег llama.cpp. Собирайте тег,
под который заплаты писались (`LLAMA_TAG=b11235`, по умолчанию), или откройте issue.

**Модели качаются медленно / обрываются.** `python3 scripts/download-models.py` продолжает с места
обрыва; при необходимости задайте зеркало в `HF_ENDPOINT`.
