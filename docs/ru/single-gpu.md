# Одна MI50

**Ничего на этой странице автор не измерял** (на стенде две карты по 16 ГБ). Здесь то, что следует
из замеров и арифметики памяти.

## 1× MI50 32 ГБ

Помещается: модель 16.1 ГБ + голова MTP 1.4 ГБ + KV-кэш (16 слоёв полного внимания; 128K контекста —
примерно 8 ГБ) + рабочие буферы. `./run.sh` запускает на одной карте с MTP; если не стартует —
уменьшите `CTX`.

Ожидаемая скорость: одна MI50 читает веса примерно так же быстро, как `-sm layer` на двух картах
(~22 ток/с без спекуляции). MTP умножает это на число принятых токенов за шаг, а заплата `mmvq` как
раз делает дешёвым проход проверки на 4 токена — на одной карте она важна **больше**, чем на двух.
Грубая оценка: 30–40 ток/с. Пришлите свои цифры (`./bench.sh`).

## 1× MI50 16 ГБ

Один только файл 27B Q4_0 весит 16.1 ГБ (карта 16 ГиБ = 17.18 ГБ, минус драйвер и буферы):
**не помещается** с полезным контекстом. Варианты:

- **Добавить вторую карту.** Две MI50 по 16 ГБ — это и есть измеренная конфигурация.
- **Квант поменьше той же модели** (например `IQ3_S`, ~11.8 ГБ). Оговорка: у K- и I-квантов нет
  быстрого кернела под gfx906, на байт это медленнее Q4_0, и заплата `mmvq` (только Q4_0) не
  сработает. Качество тоже ниже. Положите файл в `models/` и запустите
  `FORCE=1 MODEL=ваш-файл.gguf CTX=16384 ./run.sh` (голова MTP Q4_0 может и поместиться; если нет — `MTP=0`).
- **Модель поменьше в Q4_0 с головой MTP** (например, dense или MoE Qwen3.5/3.6, которая влезает):
  заплаты общие — Gated DeltaNet подходит к любому гибриду Qwen3.5/3.6/3.8, `mmvq` — к любой Q4_0-модели,
  где бывает проход проверки/пакета на 2–8 токенов.

## Образ с любой моделью

Образ — обычный llama.cpp `b11235` + заплаты, точка входа — `llama-server`:

```bash
docker run --rm --device=/dev/kfd --device=/dev/dri --group-add video \
  --security-opt seccomp=unconfined -v /путь/к/моделям:/models:ro -p 127.0.0.1:8080:8080 \
  mi50-llama:b11235 --model /models/ваша-модель-Q4_0.gguf -ngl 999 --flash-attn on \
  --cache-reuse 0 --cache-ram 0 --ctx-checkpoints 0 --ctx-size 32768
```
